# `@haybarn/ext-storage_compat-h1-5-5-linux-x64`

Platform-specific binary for the **storage_compat** extension on **linux/x64 (glibc)**, built against [Haybarn](https://github.com/Query-farm-haybarn/haybarn) **1.5.5**.

> **Source:** [https://github.com/carlopi/duckdb-storage-compat](https://github.com/carlopi/duckdb-storage-compat)

## You probably don't want to install this directly

Install the meta-package instead — npm will resolve to exactly the matching leaf for your platform:

```sh
npm install @haybarn/ext-storage_compat-h1-5-5
```
